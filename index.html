Réalité augmentée pour la classe

QR Magik

Collez un code sur une fiche, un affichage ou un cahier. L’élève le scanne avec l’appareil photo de la tablette : le texte est lu à voix haute, l’image ou la vidéo s’affiche. Aucune application à installer, aucun compte.

1 · Choisir l’augmentation
Où mettre mes propres fichiers ?
  1. Créez un compte gratuit sur github.com (une seule fois).
  2. Cliquez sur + → New repository, nommez-le mes-modeles, cochez Public, puis Create repository.
  3. Cliquez sur uploading an existing file, glissez vos fichiers (.glb, .jpg, .png, .mp3, .mp4), puis Commit changes.
  4. Cliquez sur un fichier dans la liste et copiez l’adresse de la page dans la barre du navigateur.
  5. Collez-la ici. QR Magik la transforme en lien direct, puis touchez Vérifier le fichier.

Fichiers de 20 Mo maximum, objets 3D de préférence sous 10 Mo. Si vous modifiez un fichier, déposez-le sous un nouveau nom : l’ancien lien peut rester en mémoire plusieurs heures. Les fichiers d’un dépôt public sont visibles par tous : n’y mettez ni photos d’élèves ni données personnelles.

Adresse de publication de l’outil

Les codes ouvrent cette page en mode lecteur. Indiquez l’adresse où vous avez mis en ligne les fichiers de QR Magik (GitHub Pages, ENT, Forge des communs numériques éducatifs…). Sur GitHub Pages, l’adresse est reconnue toute seule.

2 · Le code obtenu

Appui long ou clic droit sur le code pour l’enregistrer.

Adresse manquante. Ce code s’ouvrira seulement après la mise en ligne de l’outil : renseignez l’adresse de publication sous le formulaire.
3 · Planche à imprimer

Vos codes

  1. Mettre l’outil en ligne une fois

    Déposez ce fichier HTML sur un hébergement en https. Une seule fois pour toute l’année.

  2. Créer les codes

    Un texte court tient dans le code lui-même : rien n’est stocké sur un serveur. Images, sons et vidéos sont appelés par leur adresse.

  3. Scanner en classe

    Appareil photo de l’iPad, de l’iPhone ou de la tablette Android, puis « Voir en réalité augmentée » ou « Écouter ». Fonctionne aussi hors connexion pour le texte une fois la page chargée.
